Retail Analysis – Loan Risk Data Pipeline

A PySpark-based data engineering project focused on processing and analyzing loan data to identify risk patterns and support better lending decisions.
The project covers data cleaning, transformation, validation, optimization, and analysis using PySpark and Spark SQL, with data stored in CSV and Parquet formats and exposed through external tables for downstream analysis.

Tech Stack: 
PySpark • Spark SQL • Python • Parquet • SQL • CI/CD • Git • GitLab • Jenkins
